# Preserved community texts

Accepted, authorized Markdown copies are stored at `<issue-number>/dd.md`. Each
copy includes author attribution, the original source, the canonical submission
issue and the submitter's permission declaration, followed by the submitted text.

These source texts are outside `LICENSE-DATA` and the repository's MIT code license.
Copyright remains with the original rights holder. Permission is limited to
preservation and public display with attribution; no new license is implied.
Original FlipHTML5 book texts are not included.

The dataset records the exact path and SHA-256. Do not edit a preserved copy without
a reviewed correction and matching metadata update. Markdown stays inert at rest;
readers must disable raw HTML execution and must not download remote images to
work around unavailable sources. External media can still disappear.
